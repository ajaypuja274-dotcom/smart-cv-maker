# Smart CV Maker – release package

## Included
- `index.html`: dashboard + resume builder + job categories/templates.
- `about.html`, `contact.html`, `privacy-policy.html`, `terms.html`, `disclaimer.html`.
- `robots.txt`, `sitemap.xml`, `manifest.webmanifest`.

## Before publishing
1. Replace `YOUR-GITHUB-USERNAME` and `YOUR-REPOSITORY` in `robots.txt` and `sitemap.xml` with the exact GitHub Pages URL.
2. Add a real support email to `contact.html` and the privacy policy.
3. Review the legal pages for your country and business.
4. Upload all files to the root of your GitHub Pages repository and commit.
5. Open the live site on Android and test every category, template, photo upload, multiple entries and PDF printing.

## Important limitations in this static release
- Login/signup and cloud resume storage are not enabled. They require a secure backend and authentication provider.
- AdSense is not enabled and approval is not guaranteed. Apply only after the site has original, useful content and complete legal/contact information.
- Google Search Console ownership verification and sitemap submission must be completed by the site owner.
- Browser-local draft autosave is local to the same browser/device; it is not cloud backup.
